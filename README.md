### 🚀 Featured Work

**1. Resume Skill Extractor (Llama 3 8B)**
* **What:** An end-to-end LLM pipeline that extracts core responsibilities and technical skills from unstructured job descriptions.
* **How:** Curated and cleaned 3,000+ records via Gemini 1.5 API, fine-tuned `Meta-Llama-3-8B-Instruct` using QLoRA (4-bit), and mathematically merged the weights for serverless deployment.
* **Result:** Eliminated the manual effort of tailoring resumes by providing candidates with instant, highly accurate lists of required skills.

**2. Docker ML API Hub**
* **What:** A containerized environment for running and interacting with machine learning models.
* **How:** Packaged ML environments using Docker and exposed model inference capabilities via REST APIs using Python.
* **Result:** Streamlined the deployment process, allowing front-end applications to interact with ML models reliably across any environment.
